# Developer Portfolio

정적 HTML/CSS/JavaScript로 만든 GitHub Pages용 포트폴리오입니다. 패키지 설치나 빌드 과정 없이 저장소의 Pages 설정만 하면 배포할 수 있습니다.

## 내 정보로 바꾸기

- `index.html`에서 소개 문구, 경력/관심사, 프로젝트 이름과 설명을 수정합니다.
- `https://github.com/`, `https://www.linkedin.com/`, `hello@example.com` 링크를 본인 계정과 이메일로 바꿉니다.
- 페이지 제목과 설명은 `<title>` 및 `meta name="description"`에서 변경합니다.
- 색상과 반응형 레이아웃은 `styles.css`에서 조정합니다.

## GitHub Pages 배포

1. 이 파일들을 GitHub 저장소의 기본 브랜치 루트에 커밋하고 푸시합니다.
2. 저장소의 **Settings → Pages**를 엽니다.
3. **Build and deployment → Deploy from a branch**를 선택합니다.
4. 기본 브랜치와 `/(root)`를 선택하고 저장합니다.

저장소 페이지에서 제공하는 주소로 접속하면 사이트를 확인할 수 있습니다. 사용자 사이트 주소(`username.github.io`)로 쓰려면 저장소 이름을 `username.github.io`로 만드세요.
